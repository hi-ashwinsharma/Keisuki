# Security Policy

## Supported Versions

Security updates and patches are actively maintained on the latest minor release version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Keisuki team and maintainers take the security of our application and our users' privacy very seriously. If you believe you have found a security vulnerability in Keisuki (including data leakage, authentication vulnerabilities, or local storage exploits), please report it responsibly.

### How to report:
1. **Do NOT publicly disclose** the issue on GitHub Issues, pull requests, or public discussions.
2. Please send a report via email to **[hiashwinsharma@gmail.com](mailto:hiashwinsharma@gmail.com)** or submit a private security advisory through GitHub's [Security Advisories](https://github.com/hiashwinsharma/Keisuki/security/advisories/new) page.
3. Include in your report:
   - A description of the vulnerability.
   - The steps necessary to reproduce the issue (proof-of-concept code, screenshots, or sample payloads).
   - The potential impact on users and data security.
   - Any suggested mitigations or fixes.

### Response timeline:
- **Acknowledgement**: You will receive an initial response acknowledging receipt within **48 hours**.
- **Assessment**: We will verify and assess the severity within **5 business days**.
- **Resolution**: We will provide a timeline for a patch or security release and coordinate public disclosure with you once resolved.

Thank you for helping keep Keisuki and our community safe and secure!
